## 📋 ระบบทั้งหมด

| # | ระบบ | คำอธิบาย |
|---|------|----------|
| 🎒 | **ระบบของหายได้คืน** | บันทึก ค้นหา และจัดการของหาย-ของได้ พร้อมรายงานสรุป |

| ✅ | **ระบบเช็คชื่อนักเรียน** | เช็คชื่อรายวัน รายห้อง พร้อมสถิติย้อนหลัง |

### ✨ จุดเด่น

- 🔗 **ฐานข้อมูลนักเรียนร่วมกัน** ทั้ง 5 ระบบ
- ☁️ **เก็บข้อมูลใน Google Sheets** ของคุณเอง ไม่ต้องเสียค่า hosting
- 📱 **Responsive** ใช้งานบนมือถือได้ลื่นไหล
- 💾 **Backup/Restore** สำรองข้อมูลเป็น JSON ได้ทุกเมื่อ
- 📊 **Export Excel** ทุกระบบส่งออกเป็น .xlsx ได้
- 🆓 **ใช้ฟรี 100%** ไม่ต้องสมัครบริการอื่นใด

## 🚀 วิธีติดตั้ง (ใช้เวลา ~5 นาที)

### ขั้นตอนที่ 1: ดาวน์โหลดไฟล์
- กดปุ่ม 🟢 **Code** → **Download ZIP** ที่หน้านี้
- หรือ Clone:
  ```bash
  git clone https://github.com/YOUR_USERNAME/nongsamrong-school-system.git
  ```

### ขั้นตอนที่ 2: สร้าง Apps Script Project
1. ไปที่ [script.google.com](https://script.google.com)
2. กด **+ New project**
3. ตั้งชื่อโปรเจกต์ เช่น `ระบบโรงเรียนหนองสำโรงวิทยา`

### ขั้นตอนที่ 3: คัดลอกโค้ดทั้งหมด
1. **Code.gs** — ลบเนื้อหาเดิม แล้ววางโค้ดจาก `Code.gs`
2. กด ➕ ข้าง Files → **HTML** สร้างไฟล์ตามนี้:
   - `index`
   - `favicon`
   - `lostfound`
   - `conduct`
   - `attendance`
   - `magiceye`
   - `late`
3. คัดลอกเนื้อหาแต่ละไฟล์ HTML วางลงไป (**ชื่อไฟล์ต้องตรงเป๊ะ**)

### ขั้นตอนที่ 4: Deploy
1. กด **Deploy** → **New deployment**
2. กดเฟือง ⚙️ → เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** Me (ตัวเอง)
   - **Who has access:** Anyone (หรือ Anyone with Google account)
4. กด **Deploy** → อนุญาต permissions
5. คัดลอก **Web app URL** → เปิดใช้งานได้เลย!

### ขั้นตอนที่ 5: เปิดใช้งานครั้งแรก
1. เปิด URL → ระบบสร้าง Google Sheets อัตโนมัติ
2. ไปที่ **แท็บ "นักเรียน"** → เพิ่มข้อมูล (พิมพ์เอง หรือ Import จาก Excel)
3. เริ่มใช้งานระบบอื่น ๆ ได้ทันที


## 🛠️ เทคโนโลยีที่ใช้

- **Backend:** Google Apps Script
- **Database:** Google Sheets
- **Frontend:** HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript
- **Libraries:** SheetJS (xlsx.js) สำหรับ Import/Export Excel
- **Image Storage:** Google Drive (โลโก้/ลายเซ็น/รูปแจ้งเหตุ)

## ❓ คำถามที่พบบ่อย

**Q: ข้อมูลปลอดภัยไหม?**
A: ปลอดภัย เพราะข้อมูลทั้งหมดเก็บใน Google Sheets ของคุณเอง ไม่มีใครเข้าถึงได้

**Q: ใช้ได้กี่คนพร้อมกัน?**
A: รองรับการใช้งานพร้อมกันหลายสิบคน (จำกัดตามโควต้า Google Apps Script: 6 นาที/script execution)

**Q: ถ้าต้องการแก้ไขดีไซน์ ทำได้ไหม?**
A: ทำได้ แก้ไฟล์ HTML ใน Apps Script Editor ได้เลย แล้ว Deploy ใหม่

**Q: นำไปใช้เชิงพาณิชย์ได้ไหม?**
A: ❌ ไม่ได้ — โครงการนี้สำหรับใช้ในโรงเรียนเท่านั้น ห้ามดัดแปลง ทำซ้ำ เพื่อการพาณิชย์ หรือแอบอ้างเป็นผลงานตนเอง
