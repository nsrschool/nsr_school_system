📖 คู่มือการใช้งาน

🚀 เริ่มต้นใช้งานระบบ

  1. เปิดเมนู "⚙️ ตั้งค่าระบบ" → กรอกชื่อโรงเรียน, ปีการศึกษา, ผู้อำนวยการ → กดบันทึก
  2. เปิดเมนู "🧑‍🎓 จัดการนักเรียน" → นำเข้ารายชื่อจาก Excel หรือเพิ่มแบบทีละคน
  3. เลือกระบบที่ต้องการใช้งานจากหน้าหลัก (5 ระบบ)

📦 ระบบทั้ง 5

  • 🏆 ของหายได้คืน: บันทึกความดีนักเรียน เช่น เก็บของได้, เก็บเงินได้, อาสาช่วยงาน — ระบบจะสะสมคะแนนความดี
  • ⚠️ ตัดคะแนนความประพฤติ: บันทึกการกระทำผิดของนักเรียน เช่น มาสาย, ทรงผมผิด, ทะเลาะวิวาท — ระบบจะหักคะแนนความประพฤติ (เริ่มต้น 100 คะแนน)
  • 📋 เช็คชื่อนักเรียน: เช็คชื่อรายวันแยกแต่ละห้องเรียน — มีสถานะ มา/ขาด/ลา/มาสาย
  • 👁️ ตาวิเศษ NSR: ระบบแจ้งเหตุพบขยะหรือทำผิด ผู้แจ้งได้ +1 คะแนน ผู้ทำผิดถูกหัก -1 คะแนน
  • 🕒 บันทึกการมาสาย: มี 3 บทบาท — ผู้บันทึก, ครูเวรตรวจทาน, ผู้บริหาร พร้อมแดชบอร์ดสถิติ

💾 การสำรองข้อมูล

กดปุ่ม "💾 สำรองข้อมูล (Backup)" บนแถบด้านบน ระบบจะดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ .json เก็บไว้ในเครื่อง สามารถกู้คืนได้โดยกด "📥 นำเข้าข้อมูล (Import)"

🌐 วิธี Deploy เป็น Web App (สำหรับครูที่นำโค้ดไปใช้ต่อ)

  1. เปิด Google Sheets → สร้างไฟล์ใหม่ตั้งชื่อตามต้องการ
  2. คลิกเมนู Extensions (ส่วนขยาย) → Apps Script
  3. วางโค้ดในไฟล์ Code.gs ที่ได้รับมา
  4. กดเครื่องหมาย + → HTML สร้างไฟล์ HTML ทีละไฟล์ ตั้งชื่อ index, lostfound, conduct, attendance, magiceye, late, favicon ตามลำดับ แล้วคัดลอกโค้ดวางเข้าไป
  5. กด Save ทุกไฟล์
  6. กด Deploy → New deployment → เลือก Web app
  7. ตั้งค่า Execute as: Me และ Who has access: Anyone (หรือ Anyone with Google account)
  8. กด Deploy → ระบบจะให้กดอนุญาตสิทธิ์ครั้งแรก
  9. คัดลอก Web App URL ที่ได้รับ ส่งให้นักเรียน/ครูคนอื่นใช้งานได้

⚠️ คำเตือน

  • ปุ่ม "🗑️ ล้างข้อมูลทั้งหมด" จะลบข้อมูลทุกระบบ ไม่สามารถกู้คืนได้ ควรกด Backup ก่อนทุกครั้ง
  • การลบนักเรียนจะไม่ลบประวัติเดิม แต่ประวัตินั้นจะไม่ผูกกับ ID นักเรียนอีกต่อไป
  • โปรดอย่าแก้ไขข้อมูลใน Google Sheets โดยตรง ให้ใช้ผ่านระบบนี้เท่านั้น
